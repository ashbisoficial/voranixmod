# Ottoke Street Food

## Plataforma
- Minecraft 1.20.1
- Forge 47.x
- Java 17

## Mod ID
ottoke

## Package
com.voranix.ottoke

## Objetivo
Agregar el restaurante Ottoke Street Food con banderillas coreanas, bebidas y una estación de cocina personalizada.

## Contenido inicial
### Comidas
- Banderilla Cruda
- Banderilla Clásica
- Banderilla Mozzarella
- Banderilla Papa
- Banderilla Picante
- Banderilla Premium

### Bebidas
- Cola
- Té de Durazno
- Soda de Limón
- Soda de Naranja
- Ginger Ale

### Bloques
- Freidora
- Mostrador
- Caja Registradora
- Caja Ottoke
- Menú
- Basurero

## Principios
- Estilo visual vanilla.
- Código modular y documentado.
- Una responsabilidad por clase.
- No duplicar lógica.
